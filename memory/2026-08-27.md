### Bug #4 SubroutineExpander 0 递归防护 → **误报** ⛔
- Phase 1A matrix 写"递归函数可能无限展开（line 3810）"是**错误推断**
- 实测: `function automatic` 互相递归 f→g→f, 30s timeout 内 build 正常, exit=0, 3 nodes/2 edges
- **真相**: `SubroutineExpander.expand()` **不深入函数体重新调用 expand()** — 只对当前 call site 一次性提取形参→实参映射 + 条件分支, 不展开函数体里的 call
- 教训: subagent 看到 `_extract_assignments` / `_extract_signals_with_mapping` 等方法名 + 代码量 925 行, 误判为"会递归展开"。**没有实测过, 以后 subagent 的 "潜在 bug" 要打问号**
- 决定: **不修** (不存在 bug), 但在 spec 里明确写 "SubroutineExpander 不展开函数体内 call (设计如此, 而非缺陷)"
