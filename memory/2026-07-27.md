# 2026-07-27 (V6.3+1 / V6.3+2 修复 driver_extractor)

## 重大进展: case 套 ternary 抽取完整修复

### 起点
用户设计了 `mux_demo.sv` 5 种 mux 模式:
- y_simple_if (if/else)
- y_case (case 4:1)
- y_tern (ternary combinational)
- y_nested (case 套 ternary) — **这个失败**
- y_deep (2 层 case 套 case)

### y_nested 失败的根因
- trace fanin y_nested 返回 0 个 driver
- 8 个输入信号 (a-h) 全部"消失" — graph 断了

### 找到 3 个 bug
1. **ParenthesizedExpressionSyntax 没解包**: case RHS `(sel_f ? a : b)` 包装在 parens 里, unwrap 循环只查 `.operand` attr
2. **visitor 拿到错对象**: unwrap 后 `get_signals_with_conditions(rhs_expr)` 还是传外层 ParenthesizedExpression
3. **outer case 条件丢了**: `_signal_visitor` 给内层 sig_cond, 但 `make_edge()` 调用时没传 ctx, outer case 条件没进 edge

### Bonus 修复
- `ExpressionKind.ConditionalOp` vs `SyntaxKind.ConditionalExpression` kind 名称不一致
