### 教训 (核心)

1. **不要靠错误信息数字猜原因** — RecursionError 的 depth 数字可能误导
2. **用户怀疑往往是正确的** — "为什么会有2000层" 帮我找到了真因
3. **Cycle 是递归 bug 的常见原因** — 必须有 visited set
4. **Cache 必须是 read-write** — 只读 cache 无法 break cycle
5. **git checkout 是核武器** — 多次失败时, 回到干净状态重新分析
6. **测试真实项目比 mock 更能发现 bug** — golden 32 全过, picorv32_pcpi_mul 失败
