# P150 verify consistency id_parent_mismatch

**日期**: 2026-11-10
**状态**: ✅

## 1. 问题

P148 修复 width 后，SPI_HOST 仍有 171 条 `id_parent_mismatch`。

实际都是 generate/struct 路径中的方括号，例如：

```text
prim_ram_1p_adv.gen_ram_inst[0].u_mem.cfg_i.ram_cfg
```

旧检查：

```python
if "[" in n and not n.startswith(parent + "["):
    id_parent_mismatch
```

把**祖先路径里的 generate 下标**误当成 bit-select。

## 2. 修复

只检查节点相对 parent 的**直接关系**：

```python
direct_child = (n.startswith(parent + ".") or n.startswith(parent + "["))
```

祖先中的 `[0]` 不再触发。

## 3. 实测

```text
after:  0
bit_mapping: pass
```

P148 的 width 修复 + P150 的 parent 修复后：

```text
718 -> 0 bit violations
```
