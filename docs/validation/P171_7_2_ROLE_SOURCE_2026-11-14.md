# P171.7.2 clock/reset role source label

**日期**: 2026-11-14
**状态**: ✅ 完成

## 1. 背景

`audit --checks risk|verification_gaps` 的 `role`（clock/reset/valid/ready/data）
是按信号名 regex 推断的，不是语义证明。

## 2. 修改

每个 audit row 新增：

```text
role_source = "name_heuristic"
role_method = "name_regex_v1"
```

覆盖：

- `check_risk` 的 risk rows；
- `check_verification_gaps` 的 gap rows。

## 3. 边界

- 这不改变 role 判定，只把推断来源显式化；
- `clk_en`/`clockgate`/`reset_done` 等仍可能被名字误归；
- 消费方必须把 `role_source=name_heuristic` 当等级较低的证据。
