## What is correct (verified, not assumed)

1. **Refresh failure is explicit and non-destructive.** `_current_cache_key()` (`graph_session.py:75-90`) now raises when `_build_identity()` returns `None`. No silent `None` → `refresh() returns False` path remains for file/filelist modes.
2. **Graph identity/generation preserved on failure.** Repro 1: after `src.unlink()`, `refresh()` raises, `gs.generation == 0`, `gs.graph is g0` (same object). `_cache_key` and `_generation` are updated only after a successful rebuild (`graph_session.py:116-118`).
