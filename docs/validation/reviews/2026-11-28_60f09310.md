## Findings

**C1 — P2 — compact projection drops the structured source-truncation marker.**
`src/sv_query/cli/core/semantic/trace_evidence.py:208-213`: `_compact_evidence.keep` omits
`source_text_truncated`. Since `evidence_to_dict()` now caps `source_text` at 4000, a compact
response can contain truncated `source_text` without the boolean marker; only the inline
`\n... [truncated]` suffix reveals it. Repro: synthetic 4123-char evidence → after compact,
keys are the five original ones and `source_text_truncated` is absent while text ends
`[truncated]`. No real picorv32 signal triggers this (max `source_text` 148 chars). Not P1:
truncation still survives the projection as explicit text, and `is_verified` is unaffected.
Suggested fix: add `source_text_truncated` to the compact keep tuple (accepting a compact
shape change), or document the inline suffix as authoritative for compact. Protocol §3.2 is
satisfied in substance but the structured-marker path is inconsistent with the new contract.

**C2 — P2 — D12 baseline normalization removes the whole `evidence_payload` contract section.**
`sim/tests/unit/test_d12_error_envelope.py:365-367` now pops `json_contract.evidence_payload`
from both sides. This is correctly additive and passes, but it reduces frozen-baseline coverage
for all evidence contract fields, not just the two added markers. A narrower normalization
(pop only `enclosing_chain_truncated` / `source_text_truncated`) would preserve more signal.
Residual coverage is adequate: `test_json_contract.py::test_evidence_contract` still asserts
exact key-set equality against the live contract (and passes).

**C3 — governance (not a code defect) — item not formally closable yet.**
`PLAN.md:22,613` and `CURRENT_TODO.md:12` still say `<进行中>` for P194.5.11, and no worker
artifact for `60f09310` exists under `docs/validation/reviews/`. CODE_REVIEW_PROTOCOL §1/§5/§7
requires this change (verification/evidence projection + contract) to have a verbatim-archived
worker artifact and consistent PLAN/TODO status before it can be declared closed. The
