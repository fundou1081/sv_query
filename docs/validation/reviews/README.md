# Review artifacts

Worker-only review reports are stored here as:

```text
YYYY-MM-DD_<head7>.md
```

The report is copied verbatim from the independent worker. Do not edit its
verdict, severity, or findings. See
[CODE_REVIEW_PROTOCOL](../../dev/CODE_REVIEW_PROTOCOL.md).

An artifact with an open P0/P1 blocks merge and release until the implementer
reworks and an independent worker re-audits the fix.
