## Empirical verification (points 1–6)

### 1. quiet is ContextVar-scoped; exits restore; concurrent contexts — PASS

`_QUIET: ContextVar[bool] = ContextVar("sv_query_quiet", default=False)`;
`quiet_context()` uses `token = _QUIET.set(enabled)` / `_QUIET.reset(token)` in `finally`;
`is_quiet()` reads `_QUIET.get()`. Harness `/tmp/p1978_behavior.py` results (74 checks,
73 PASS, 1 intentionally-wrong expectation corrected below as non-finding):

| Probe | Result |
|---|---|
| baseline `is_quiet()` | False |
| nested `quiet_context(True)` → `quiet_context(False)` | True → False → True → False on exit |
| `set_quiet(True)` inside `quiet_context(False)`, then exit | value True inside, False after (token reset discards inner set) |
| two threads: `quiet_context(False)` vs `quiet_context(True)` | `{'tFalse': False, 'tTrue': True}`; main context unchanged |
| `asyncio.gather` of two tasks with opposite values | `[False, True]`; main context unchanged |

`set_quiet()` (47–57) is retained and now sets the **current context** rather than a
process global — backward-compatible for single-threaded callers; it does not leak across
threads/tasks. (Docstring nit recorded as P2-4.)
