### 2.2 F2 — 关闭（独立探针复现旧失败 + 验证新行为）

关键代码（`src/sv_query/trace/core/query/signal.py`）：

- `_expr_source_bits`：`ir = self._edge_expression_ir(edge)`；命中后 `mapped = output_source_bits(...)`；`if mapped is None: return None`（注释「IR exists: unknown must not fall back to legacy」）；否则才返回位列表。
- `_expr_dst_bits`：同样 IR 命中即返回，`mapped is None → return None`；legacy `shift_amount` 分支只在 IR 未命中时可达。
- `bit_mapping.py`：`_RESULT_HANDLERS`/`_INPUT_HANDLERS` 无 `Call`/`Unknown` handler → `_result`/`_input` 返回 `None`，沿递归向上传播。

探针 `/tmp/p1985_reaudit_probe.py` 实测（`edge.expr_id` 均存在，即 IR 确实命中）：

| 用例 | edge 仍带 legacy `op/shift_amount` | IR 子树 | `_expr_source_bits` | `_expr_dst_bits` |
|---|---|---|---|---|
| `y=f(a)<<4'd2`（Call） | `LogicalShiftLeft / 2 / a` | `Call(reason='function call f; bit mapping unknown')` | `None` | `None` |
| `y=a<<b`（动态） | `LogicalShiftLeft / None / a` | 子节点 `SignalRef b`（非 Literal） | `None` | `None` |
| `y=a<<4'dx`（未知字面量） | `LogicalShiftLeft / None / a` | `Literal 4'bxxxx` | `None` | `None` |

→ IR 存在时 `None` 一律原样传播，**不再**产出初审核中的伪造 `['top.a[0]']` / `['top.y[2]']`。调用方（`signal.py:219/1500/1625/1673` 等）对 `None` 走 coarse/bus-level 回退，属显式 unknown，不是伪造精确位。铁律 2/13 与契约 §8「Call → unknown / partial must never be reported as verified」得到满足。

**revert 敏感性**：运行时 monkeypatch `_edge_expression_ir → None` 后，同一 Call 边 `_expr_source_bits(...,2)` 恢复为 `['top.a[0]']`、`_expr_dst_bits(0)` 恢复为 `['top.y[2]']`——即新增 `test_ir_unknown_does_not_fall_back_to_legacy` 的 `is None` 断言在 IR 路由被移除时必然失败。测试对新行为敏感。
