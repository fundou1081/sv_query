failure example uses a *supported* op (`paths`).

failure example's op/message from `paths` to `stats`.
Test gap: no doc test asserts the illustrative failure op is actually unsupported (the authoritative
`capabilities --json` is correct, so reader impact is limited — hence P2, not P1).
