### 3. Ascending / nested / wide / narrow / literal / dynamic / mismatch — **FAIL (new regression)**

Correct and verified:
- `{y1,y0} = {a[1:0],b[1:0]}` (ascending, 2-bit targets): `a[1:0]->y1`, `b[1:0]->y0`
  + correct per-bit edges; no unknowns.
- `{y} = {a[1:0],b[1:0]}` (wide LHS): segment + per-bit edges correct.
- `{y2,{y1,y0}} = {a,{b,c}}` (nested): `a->y2, b->y1, c->y0`, all with refs.
- literal `2'b10` → `concat_segment_unknown`, no literal edge.
- dynamic `a[idx]` → `concat_segment_unknown`, only `a[0]->y0` with a ref.
- width mismatch → `concat_layout`, zero edges, no aggregate/top.{...} edge.
- LE split on either side matches explicit reference (see point 1).

**Regression (new, blocking):** descending-declared slices split into multi-bit
targets lose per-bit expansion. Verified cases:

```
(a) {y[3],y[2:0]} = {a[2:0], b}          [audit-verified case]
    HEAD edges:      b->y[0], a[0:1]->y[1:2], a[2]->y[3]   unknowns: []
    HEAD fanin:      y[0]->b, y[1]->[], y[2]->[], y[3]->a[2]
    target fanin:    y[0]->b, y[1]->a[0], y[2]->a[1], y[3]->a[2]
    => y[1], y[2] silently have NO drivers.

(b) {y1,y0} = {a[3:0]}  (y0,y1 each 2-bit)
    HEAD fanin:      y0[0]->a[0:1], y0[1]->a[0:1], y1[0]->a[2:3], y1[1]->a[2:3]
    target fanin:    y0[0]->a[0],   y0[1]->a[1],   y1[0]->a[2],   y1[1]->a[3]
    => coarse superset: false driver a[1] reported for y0[0], no unknown recorded.
```

Root cause: `concat_layout.py:81-88` now computes `start = lsb + direction*lo`,
`end = lsb + direction*hi` and returns `bit_range=(start, end)`. For a descending
declaration (`a[2:0]`, `a[3:0]`) this produces **ascending** sub-ranges such as
`a[0:1]`, `a[2:3]`. `_expand_slice_bit_nodes` only expands node ids matching
`[hi:lo]` with `hi>lo` (`graph_builder.py:309-319`, `392-427`), so no per-bit edges
are created; `trace_fanin` of the individual bits then returns empty (case a) or
falls back to the aggregate bus (case b). The initial target emitted descending
sub-ranges (`a[1:0]`, `a[3:2]`) and precise per-bit fanin.

The committed suite has no test for descending multi-bit concat splits, so the
green gate does not detect this.
