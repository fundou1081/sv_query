# P136.5 solve…before / dist extraction

**日期**: 2026-11-09
**问题**: `trace constraints` 不输出 `solve…before` 和 `dist` 权重
**结果**: 两者进入 `constraint_block` schema；保持 solve 不是值约束

---

## 1. solve…before

解析：

```systemverilog
constraint c_ab {
  a < b;
  solve a before b;
}
```

输出：

```json
"constraints": [{
  "block": "rnd_item.c_ab",
  "solve_before": [{"node": "rnd_item.c_ab::solve_1",
                     "before": ["rnd_item.a"]}]
}]
```

实现：

- semantic `SolveBeforeConstraint.syntax` 解析 `solve … before …;`
- `CONSTRAINT_SOLVE` 节点保留 `extra.before/after`；
- `HAS_BEFORE` 只指向 before 变量；
- **不把 solve 变量加入 block 的 CONSTRAINS 值约束**（旧测试锁定：solve 不是值约束）。

## 2. dist

解析：

```systemverilog
constraint c_de {
  e dist {0 := 1, 1 := 3};
}
```

输出：

```json
"dist": [{"node": "rnd_item.c_de::expr_0",
          "items": [{"value": "0", "kind": "PerValue", "weight": "1"},
                    {"value": "1", "kind": "PerValue", "weight": "3"}],
          "confidence": "syntactic"}]
```

保留原始 dist 文本，不在这一层解释概率/权重归一化。

## 3. schema

`constraint_block` 新增：

```text
solve_before: array<object>
dist: array<object>
```

`trace constraints`、`class --relations`、`trace tb-join` 的 constraint 输出保持一致。

## 4. 测试

```text

```

## 5. 边界

- solve 只输出 before；after 变量记录在 solve 节点 extra，不在 result schema；
- dist 是文本，不做权重计算；
- 嵌套/条件 constraint 的 solve/dist 仍需扩展；
- 继承传播的 solve 节点可能被复制，需后续图谱核对。
