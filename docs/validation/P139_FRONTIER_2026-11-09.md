# P139 boundary-aware guided trace

**日期**: 2026-11-09
**结果**: 新增 `trace frontier`；core 不自动识别 FIFO

---

## 1. 命令

```bash
sv_query trace frontier <signal> \
  --filelist ... | --from-snapshot ... \
  --direction fanin|fanout|both \
  --max-depth 8 --json
```

输出：

```json
{
  "signal": "...",
  "frontier": [
    {"direction": "fanout", "node": "...", "reason": "no_structural_edge",
     "instance": "...", "path": ["..."],
     "next_probes": ["connections ...", "ports ..."]}
  ],
  "summary": {"frontier_count": 1, "truncated": false,
              "max_depth": 8, "max_frontier": 50},
  "note": "generic boundary frontier; no semantic classification"
}
```

## 2. 实现原则

- 只走 `DRIVER` / `CONNECTION` / `BIT_SELECT`
- 遇 `INSTANTIATED_MODULE` → `instance_boundary`，instance 指向该实例
- 无结构边 → `no_structural_edge`
- 纯环/所有邻居已见 → `cycle_or_all_seen`
- 超过 depth → `depth_limit`
- 不写图、不加边、不做语义分类
- `max_frontier` 是全局上限，`path` 字段记录到断点的路径

## 3. I2C 示例

```text
nakok.q fanout:
  fmt_fifo_wdata[12]
  -> u_fifos...wdata_i[12]
  frontier at u_inp_buf.wdata_i[12]
```

agent 接着查：

```text
connections u_inp_buf
instances u_inp_buf
```

再读 `i2c_fifo_sync_sram_adapter.sv`，决定是否需要外部 boundary map。

## 4. 测试

```text
test_frontier.py: 5 passed
```

覆盖：

- boundary + next probes；
- unknown signal / invalid direction 明确失败；
- 纯环有显式 `cycle_or_all_seen`；
- `max_frontier` 全局上限；
- `note` 不含语义分类；
- 不修改图。

## 5. 边界

- 不判断 FIFO/state 语义；
- 跨边界仍需外部 adapter；
- frontier 深度/数量有限；
- 不是 P140 two-endpoint auto relation。
