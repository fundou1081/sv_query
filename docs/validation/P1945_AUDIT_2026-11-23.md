# P194.5a–c audit — findings and disposition (2026-11-23)

> **Status**: P1s fixed (P194.5e/f/g); P194.5d is governed by the acceptance
> charter in `P1945D_ACCEPTANCE_CHARTER_2026-11-27.md`.
> **Scope**: independent audit of P194.5a–c at HEAD `b9b81da5`.

## P1 findings

### P1-1 compact trace drops uncertainty/truncation markers

`--compact` drops `truncated_by_depth`, `function_call`,
`runtime_system_call`, `condition_truncated`, `cycles_detected`, and
`condition_analysis_incomplete`. A depth-truncated or function-dependent answer
can look complete in compact mode. Track as P194.5e.

### P1-2 controlflow mixed-driver false `complete`

`_label_unmodeled_inline()` returns early when any if/case-conditioned driver
exists, so an inline continuous-assign condition on the same signal is not
reported. Repro: `assign y = a & (state_q == IDLE)` plus an `always_comb`
driver yielded `condition_status="complete"` and no warning. Track as P194.5f.

### P1-3 session `paths` hides unknown endpoints

`GraphSession.paths("top.nope", "top.y")` currently returns
`{"found": false, "mode": "data"}`. CLI `paths` returns a structured
`E_SIGNAL_NOT_FOUND` failure. Track as P194.5g.

## P2 findings

- inline-condition detection uses a source regex, not semantic AST; false
  positives (`a && b`) and false negatives (`a > b`);
- CURRENT_TODO/INDEX counts and completed-leaf lists were stale;
- compact capabilities reports `counts.total=45` but lists 39 commands without
  explaining hidden exp commands;
- no tests for compact truncation, mixed-driver controlflow, path failures;
- P194.5d has no acceptance charter (dataset, ground truth, token accounting,
  baselines, sample size).

## Disposition

P194.5a–c implementation remains in git, but C-61/C-62/C-63 are downgraded until
the P1 fixes land. P194.5d is blocked by P194.5e–h. No external benchmark claim
is made.
