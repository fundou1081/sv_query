## 1. 共享 assignment scanner

把 assignment 选择逻辑从 CLI 收回 core：

```text
src/sv_query/trace/core/source_assignment.py
  is_reset_condition / strip_block_comments / line_is_lhs
  find_functional_assignment / find_assignment_near
```

- CLI `trace_evidence` / `trace_profile` 不再各自维护一份 regex；
- resolver `_assignment_line_from_file` / `_assignment_line_in_snippet` 使用同一份实现；
- `find_assignment_near` 按 hint 选最近 functional 候选；
- `line_is_lhs` 支持 case label、one-line always/if+begin 前缀。

## 2. 非 ASCII offset

`_snippet_from_syntax` 之前用 Python string 下标切 pyslang 的 UTF-8 byte offset，
非 ASCII 注释会让 enclosing snippet 错位。现在按 UTF-8 bytes 切片再 decode。

## 3. class evidence（保留既有契约）

class property 的完整 evidence（class + constraint）在
`test_class_property_full_credibility` 中要求 `is_verified=True` / credibility>=0.4，
因此不做全局降级；class 声明本身仍可能显示 `class packet;`，这是已知 NIT
（class 上下文 evidence，不是 assignment line）。

## 4. 保留的已知限制

- 默认 `--preprocess` 插入 `timescale`，enclosing snippet 行号可能 +1
  （assignment line 已修正）；见 KNOWN_LIMITATIONS §3.9.1。
- class property evidence 仍可能指向 class 声明/上下文，而非成员赋值行；
  既有 `test_class_property_full_credibility` 要求 class + constraint 为 verified。
