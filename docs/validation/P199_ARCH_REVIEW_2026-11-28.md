# Requirements → architecture defect review (0.3.9)

**Status**: review only; no code fix in this document.
**Input**: independent worker audit `/tmp/worker_039_arch.md`, archived as
[2026-11-28_fe379c03.md](reviews/2026-11-28_fe379c03.md).
**Release**: 0.3.9 is operationally healthy but ships three pre-existing P1
defects; a **0.3.10 fast-follow** is required.

## 1. Requirement model

The product promise is not "more analysis"; it is **queryable RTL facts whose
conclusions can be verified or refuted**:

| Requirement | Expected guarantee |
|---|---|
| R1 canonical identity | every signal resolves to a stable id; ambiguous/not_found explicit |
| R2 data-edge authority | CLOCK/RESET/BIT_SELECT are never data drivers/paths |
| R3 evidence | `is_verified=true` means an authoritative assignment/claim, not token coincidence |
| R4 objective verification | `verify` reports pass only with complete coverage; unknown/truncated explicit |
| R5 explicit failure | malformed request, unsupported op, bad file type => structured JSON error |
| R6 single authority | one edge policy, one literal classifier, one session contract |
| R7 semantic AST | facts come from pyslang semantic AST, not regex/text guesses |
| R8 reproducibility | same input -> same graph; cache/snapshot metadata agrees |

## 2. Confirmed P1 defects

### A1 — `drivers --depth 1` / `verify claim type=driver` accept CLOCK edges

`drivers top.q[14:12] --depth 1` returns both `top.d` and `top.clk`;
`verify claim {"type":"driver","driver":"top.clk"}` returns `verified`.
`paths --directed` and `verify claim type=path` correctly reject the same pair.

Architecture cause: `SignalTracer._find_drivers` uses all incoming pairs; only
the recursive path applies `DATA_EDGE_KINDS`. `verify_driver` inherits the
unfiltered depth-1 surface. The shared edge-policy authority
(`trace/core/graph/contracts.py`) is not used by every fanin consumer.

### A2 — `trace evidence` can verify a condition line

`trace evidence picorv32_axi.picorv32_core.mem_rdata_q[31:12]` returns line 437
(`if (COMPRESSED_ISA && mem_done ...)`) with `is_verified=true`,
`credibility_score=1.0`; the assignment is at line 470.

Architecture cause: `Evidence.is_verified` is token presence across
`enclosing_*`/`source_expr`, not "source line is an LHS assignment to this
signal". `edge.condition` is promoted to `source_expr` when no assignment text
is found. C-17/C-78 only cover the functional-line heuristic, not this authority
check.

### A3 — literal classification by ID regex

`verify consistency --full` on picorv32 reports **36 false
`fanin_not_reciprocal` violations** for `32'dx`/`1'bx` drivers. Graph nodes are
already `NodeKind.CONST`, but verification uses a regex over the node id.

Architecture cause: a fact-layer regex survives where semantic node kind is
available. This violates "single concept authority" and causes phantom
violations on a flagship real project.

## 3. Confirmed P2 defects

| ID | Defect | Architecture cause |
|---|---|---|
| W039-04 | snapshot evidence picks a CLOCK edge (trap line 1188, unverified) over a driver | snapshot candidate ranking ignores `DATA_EDGE_KINDS`; const/reset key comes first |
| W039-05 | 145 cpuregs drivers report `condition_unconditional=false` with no condition data | absence of path_info is encoded as a definite boolean instead of `unknown/null` |
| W039-06 | documented session `arguments` object fails with `E_HANDLER_FAILED` | `SESSION_CONTRACT` documents nested args; handlers read only top-level fields |
| W039-07 | session `verify_consistency` only implements `connection`; CLI supports reciprocity/bit | session and CLI share a name, not a verifier surface |
| W039-08 | `ports serv_csr` fails; only elaborated instance path works | ports filters `node.module == module`; module-name namespace unresolved |
| W039-09 | snapshot `edge_count=5771`, graph unique edges 4540 | raw serialized edge count vs canonical deduplicated count |
| W039-10 | `snapshot save foo.v --json` emits plain stderr, empty stdout | file-type failure bypasses the structured JSON envelope |

## 4. Requirement → component → gap

```text
R1 identity      CLI resolver / graph IDs       ports module-vs-instance gap (W039-08)
R2 data authority contracts.py                 only paths/dataflow consume it;
                                               drivers depth1 + snapshot evidence do not (A1, W039-04)
R3 evidence      edge provenance + resolver    token/condition can be "verified" (A2)
R4 verification  verify consistency/claim      literal regex false violations (A3);
                                               session checks incomplete (W039-07)
R5 failures      CLI/session adapters          snapshot file-type path uncaught (W039-10)
R6 single auth   contracts/registry/session    edge policy, literal classifier, args schema drift
R7 semantic AST  pyslang graph builder         A2/A3 are post-AST text/regex layers
R8 reproducibility BuildIdentity/snapshot      edge_count metadata mismatch (W039-09)
```

Common architectural root: **the project enforces "single authority" at the
graph layer, but not at the query/evidence/verification projection layer.** Each
surface re-implements a small policy (which edges count, what text verifies,
what is a literal, what session args look like), and gates test fixtures rather
than cross-surface agreement.

## 5. Fix priority (0.3.10)

1. **Edge authority (A1 + W039-04)**: make every fanin surface use
   `DATA_EDGE_KINDS`; add a negative CLOCK-only driver test and snapshot parity.
2. **Evidence authority (A2)**: `is_verified` requires an LHS assignment/semantic
   `assignment_id`; condition text moves to a non-verified field; expose
   `verification_basis`.
3. **Semantic literal classification (A3)**: use `NodeKind.CONST`; add x/z
   true-negative and mutation tests.
4. **Session contract (W039-06/07)**: accept documented `arguments` or correct
   the schema; implement or advertise per-check verification support.
5. **Identity/metadata (W039-08/09/10)**: module-name port resolution, canonical
   edge counts, structured snapshot errors.
6. **Unknown semantics (W039-05)**: tri-state condition availability.
