# Snapshot 预构建（P92 / D）

**日期**: 2026-11-07
**状态**: D 原型完成
**代码**:
- [trace_common.py](../../src/cli/core/semantic/trace_common.py)：snapshot 加载 graph + PathResolver
- [paths.py](../../src/cli/core/semantic/paths.py)：`paths --from-snapshot`
- 既有：`snapshot save` / `trace --from-snapshot`

---

## 1. 用法

```bash
# 一次性构建
sv_query snapshot save all.f \
  --filelist all.f \
  --tag design_v1 \
  --json

# 反复查询，不再 parse
sv_query drivers <signal> --from-snapshot design_v1 --depth 1 --json
sv_query loads   <signal> --from-snapshot design_v1 --depth 1 --json
sv_query paths   <src> <dst> --from-snapshot design_v1 --json
```

snapshot 默认写入 `$SVQ_SNAPSHOT_DIR` 或 cache/snapshots；不写项目目录。

## 2. 实测

### AXI

| 步骤 | 时间 |
|---|---:|
| full build + save snapshot | 27.0s |
| snapshot 文件 | 18 MB |
| load + fanin | **0.54s** |
| load + path | **0.49s** |

### SERV

| 步骤 | 时间 |
|---|---:|
| full build + save snapshot | 3.46s |
| snapshot 文件 | 4.5 MB |
| load + path | **0.23s** |

查询结果与 live graph 一致：

- AXI reg → port path：3 nodes / 2 hops；
- SERV clk path：3 nodes / 2 hops。

---

## 3. 覆盖范围

支持：

```text
drivers / loads / trace fanin/fanout / paths
```

不支持（snapshot 不含 MIG/源码）：

```text
connections / instances / hierarchy
evidence 的源码原文
```

`paths` 现在可用，是因为 PathResolver 在当前实现中只依赖 SignalGraph；
它不依赖 MIG 虚拟跳转。`connections` 仍需 live MIG，不能伪装支持。

---

## 4. 边界

- snapshot save 仍要付一次 full build；
- 一次性查询用 snapshot 不划算；
- 适合“同一设计跑 N 次 trace/path”；
- filelist/源码变化不会自动失效；tag 由调用方管理；
- snapshot 文件大（AXI 18MB / 13k+ nodes）；
- 没有自动 hash 校验；
- 不包含源码，因此 evidence 文本会退化；
- 不是 by-file 懒加载，仍是 full graph 快照。

---

## 5. 与 A 的组合

可以：

```bash
sv_query filelist prune --filelist all.f --top axi_adapter --output /tmp/pruned.f
sv_query snapshot save /tmp/pruned.f --filelist /tmp/pruned.f --tag axi_small
sv_query drivers ... --from-snapshot axi_small
```

进一步降低 snapshot 大小和 save 时间。但这是两个显式步骤，不是自动串联。

---

## 6. 结论

D 值得保留，但只解决“重复查询的启动成本”：

```text
save 一次 27s → 后续每次 0.5s
```

它不解决：

- 第一次构建；
- 变体/增量更新；
- 局部懒加载；
- connections/MIG。

下一步 C 的进入条件仍是：

```text
重复查询足够多 + paths/connections 仍需 live MIG + 局部查询占主导
```
