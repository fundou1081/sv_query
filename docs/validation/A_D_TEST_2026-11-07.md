# A/D 充分测试（P93）

**日期**: 2026-11-07
**范围**: top-aware prune + fallback + snapshot/paths
**性质**: 功能/边界/一致性测试；不是新一轮 benchmark

---

## 1. 测试矩阵

### A: prune + fallback

- 注释/字符串中的假 `module`；
- SystemVerilog `'0` literal；
- package / interface / header 保留；
- top 找不到 → 完整 filelist；
- 120 文件 chain + unused；
- macro 生成 child → pruned build 失败 → 自动回退；
- CLI `--prune` 无 `--top` / 无 `--filelist` 报错；
- prune JSON 字段只在 `--prune` 时出现，默认 schema 不变。

### D: snapshot + paths

- `paths --from-snapshot` 与 live filelist 结果一致；
- 无效 tag → 结构化失败；
- `--from-snapshot` + `--filelist` 互斥；
- snapshot 加载后 PathResolver 可用；
- AXI/SERV path 实测。

## 4. 已知边界

- prune 是文本扫描，不是 elaboration；
- macro/bind/config 可能触发 fallback；fallback 是显式重建；
- snapshot 不含 MIG，`connections/instances/hierarchy` 不支持；
- snapshot 的 evidence 源码会退化；
- snapshot 不自动失效；
- 测试数据来自本机 AXI/SERV/Pico 语料，不是外部 benchmark。

---

A: prune + fallback 可用；
D: snapshot + paths 可用，但只覆盖 graph-only 查询。
C 仍未开始。
