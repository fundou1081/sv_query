# 画图功能 v3 — 信息呈现需求 (从 5 张参考图提取)

> 来源: MediaTek CRV5 信号图、Dataflow 图、Control 图(T0/T11)、POW2 LUT 公式展开图、完整架构图(红色采样点)

## 6 个信息维度

### 1. 功能维度 — "这是什么"
| 信息项 | 示例 | 呈现 |
|--------|------|------|
| 功能块类型 | LOG2, CADD, FIFO, CRM | 矩形内大写缩写 |
| 运算符 | +, −, ×, <<, ⊕ | 小圆内符号 |
| 常量/参数 | 15, 1, 55.0, T20@31 | 小圆或矩形内数字 |
| 输入/输出角色 | r00, EVM_log2_s0 | 边旁蓝色标注 |

### 2. 数据维度 — "数据长什么样"
| 信息项 | 示例 | 呈现 |
|--------|------|------|
| 信号名 | `qrd_sort_idx`, `regen0` | Courier 等宽, 蓝或绿色 |
| 定点位宽(S) | `(S3.11)`, `(S5.3)` | 蓝色括号 |
| 定点位宽(U) | `(U3.12)`, `(U1.0)` | 蓝色括号 |
| 花括号位宽 | `{msb:lsb}` | 节点内或边旁 |
| 中间信号路径 | `-S4.4-`, `-S3.23-` | 绿色字在连线上 |

### 3. 时间维度 — "什么时候执行"
| 信息项 | 示例 | 呈现 |
|--------|------|------|
| 流水线阶段 | P1 / P2 / P3 | 红色字在虚线 border |
| 寄存/延迟单元 | D (小矩形) | 标示一拍延迟 |
| 跨拍 vs 同拍 | 穿过/不穿过虚线 | 穿过 P1→P2 = 下一拍 |
| Stage 边界 | 垂直虚线 | 蓝色, 跨所有通路 |

### 4. 数学维度 — "怎么推导的"
| 信息项 | 示例 | 呈现 |
|--------|------|------|
| 算法公式 | `m = R⁻¹e` | 图右侧独立公式框 |
| 表达式展开 | `(a-c)+j(b-d)` | 红色文字在虚线框内 |
| 位宽转换链 | `3→4→35→20` | 连续位宽标注 |

### 5. 验证维度 — "怎么确认正确"
| 信息项 | 示例 | 呈现 |
|--------|------|------|
| 条件分支 | `if sel_d && sel_f` | 边旁红字, 菱形节点 |
| 采样点 | Bit-true dump point | 红色圆点 + 图例 |
| 模块路径 | `u_pow2_s0.exp` | 等宽注释 |

### 6. 管理层级 — "这是哪份文档"
| 信息项 | 示例 | 呈现 |
|--------|------|------|
| 标题 | CRV5 – Per ss EVM | 橙色大字 |
| 分区标签 | P1/P2/P3 | cluster 顶部 |
| 保密/版权 | Confidential C, © 2022 | 右上/底部小字 |

## 统一视觉 DNA (5 张参考图共识)

- 布局: 左→右 LR
- 节点: 白底黑框直角矩形 + 小圆OP + 红框菱形MUX
- cluster: 蓝色虚线框, 标题在顶部
- 颜色: 黑+白+蓝(信号)+红(控制)+绿(路径) 五色克制
- 字体: Courier等宽(信号名) + Helvetica(标注)
- 边: 黑实线带箭头, 虚线仅用于cluster边框
