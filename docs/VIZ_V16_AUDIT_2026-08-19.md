## 经验教训

1. **HEAD detached 容易踩坑**: 对比 V16.13 vs V16.14 用 `git checkout HEAD~1` 后, 必须 `git checkout main` 回来, 不然后续 audit 跑的是 V16.13 而不是 V16.14.
2. **`isUninstantiated` filter 对 if/case generate 至关重要**: case30 (MODE=1) 只激活 gen_adder, case31 (SEL=2) 只激活 gen_subtractor, 排除 inactive branch 后 cluster label 才不会污染. V16.10/V16.11.2 是关键修复.
3. **generate_for 完整展开 ≠ 单个 i=0**: case27 必须显 `(i=0, i=1, i=2, i=3)` 列表 (F-N3 redesign), 而不是仅 `i=0`. 这是 V16.14 唯一新增能力.
4. **procedural always 块是 design limitation 不是 bug**: VIZ_DESIGN_SPEC.md Plan D1 明文只追踪 combinational assign. cases8/9/15/16/17 不应期望 dataflow SVG 包含 if/case 决策树.
