## 💡 关键发现 / 决策

1. **"入口文件"的判据不是行数，而是"读者是否需要每次都看"。**
   项目定位、设施表、版本日志都是"查得到就行"的信息；铁律、流程、提交命令是"每次都要执行"的规则。
   69 行里全部是后者。

2. **压缩过程暴露了一处过期指针**：WORKFLOW 里写着"下一个迭代从 iter_242 顺延"，
   而 iter_242 已经存在。**指针类文本要在同一迭代里检查**，否则新读者会拿到错的号。

3. **编号即契约**：铁律 1~5 保持原编号（其他文档引用"核心纪律 #2/#4"），
   产品不变量接在 6~10，既不打乱历史引用，也不用在入口再开一张表。
