## 🎯 两个"可做"的剩余缺口

1. **拼接字面量段**：`s = {a, 4'h0}` 的低位是常量，之前返回整个信号总线（高估）。
2. **常量源切片**：`y = 4'hA` 的 `fanin(y[1])` 返回常量总线 `4'b1010`，不是 `1'b1`。

## 🔧 实现

| 项 | 规则 |
|---|---|
| 常量解析 | `N'b/No/Nd/Nh`、无宽度十进制（32 位）、`'0/'1`；值 + 宽度 |
| P8.2 常量源 | 按目标位取常量值位；目标为位/切片节点用**相对位**；无符号零扩展（超出宽度 → `1'b0`） |
| P8.1 拼接字面量 | `_concat_items` 支持字面量项；目标位落在字面量段 → 常量位 |
| 无源边常量 | `a & 4'hF` / `{a, 4'h0}` 的常量操作数**没有驱动边** → 从表达式补位（`_literal_bits_at`） |
| AND 零扩展 | `a & 4'hF` 的 bit≥4：常量零扩展 → 恒 0，**信号不是依赖**（不再高估） |
| 虚拟常量节点 | 查询层临时 `1'b0/1'b1` 节点（不写图），调用方统一 `_node_any` 解析 |
| 切片位上下文 | BIT_SELECT 子切片递归时传**切片内相对位**（`y[1]` → 切片 `y[3:0]` 的 bit1） |

## 📊 效果

| 场景 | 修复前 | 修复后 |
|---|---|---|
| `y=4'hA`；fanin(y[1]) | `4'b1010` | `1'b1` |
| `y=4'h0`；fanin(y[1]) | `4'b0` | `1'b0` |
| `y=4'hF` 8-bit；fanin(y[5]) | `4'b1111` | `1'b0`（零扩展） |
| `a & 4'hF`；fanin(s[1]) | `{1'b1, a}` | `{1'b1, a[1]}`（位存在时） |
| `a & 4'hF`；fanin(s[5]) | `{1'b0, a}` | `{1'b0}`（**无误导依赖**） |
| `{a, 4'b10}`；fanin(s[0]) | `{a, b}` 类总线 | `1'b0` |

图结构**不变**（常量位是查询层虚拟节点）。

## ⚠️ 边界（KNOWN_LIMITATIONS §3.6 已更新）
