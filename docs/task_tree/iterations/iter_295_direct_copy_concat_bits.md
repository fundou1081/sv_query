## 🎯 两个剩余缺口

1. **直接拷贝** `assign y = a`：DRIVER 边没有 `source.op`（表达式就是源名），
   之前只有 F4 `one` 模式在"一侧已有位节点"时扩图才位精确；纯位查询仍总线粒度。
2. **纯拼接** `s = {a, b}`：任一位都返回两个操作数（总线），位段信息丢失。

## 🔧 改动（仍在查询层，图结构不变）

| 项 | 规则 |
|---|---|
| P7.1 直接拷贝 | 无 op 且 `expression == 源短名` → 按同索引映射（`DirectCopy`） |
| P7.1 多驱动完整性 | 位节点已有自己的驱动（F2 不提升）时，补父总线的驱动（按位映射）；两个驱动都返回 |
| P7.2 拼接 | 解析 `{...}` 顶层操作数，按**从右到左**累计宽度切段；`{a[3:0], b}` 的操作数边 `op=Slice` 也走拼接分段 |
| 边界 | 位节点不存在 → 回落总线；拼接中字面量段不分解（粗粒度，已文档） |

## 📊 效果

| 场景 | 修复前 | 修复后 |
|---|---|---|
| `assign y=a`；`t=a[3]` → fanin(y[3]) | `{a}` | `{a[3]}` |
| 同上 fanout(a[3]) | `{y, t}` 总线 | `{y[3], t}` |
| `y=a; y[3]=1'b1` → fanin(y[3]) | `{1'b1}` | `{1'b1, a[3]}`（a[3] 存在）/ `{1'b1, a}` |
| `s={a,b}; y=s[5]` → fanin(y) | `{s[5], a, b}` | `{s[5], a[1]}` |
| `s={a[3:0],b}; y=s[5]` | `{s[5], a, b}` | `{s[5], a[1]}` |
| `s={a,b}` fanout(b[1]) | `{s}` | `{s[1], t, u}` |

`one` 模式现在对直接拷贝也能位精确（源位节点存在时），不需要 `SVQ_BIT_BRIDGE=full` 扩图。

## 🧪 测试（`test_bit_precision_p7.py`，11 个）

- 拷贝：位精确 fanin/fanout、无位节点回落、多驱动两个驱动、多驱动回落
- 拼接：高/低段 fanin、fanout 偏移、切片操作数拼接、**不跨段**、字面量段粗粒度
- 既有测试更新：多驱动断言（`{1'b1}` → `{1'b1, a}`）、拼接从"粗粒度"改为"位精确"

## ⚠️ 边界

- 拼接字面量段（`{a, 4'h0}` 的低 4 位）：不分解，仍返回总线（会**高估**，非位精度承诺）
- 常量源切片、比较/逻辑/变量移位：维持 KNOWN_LIMITATIONS §3.6
