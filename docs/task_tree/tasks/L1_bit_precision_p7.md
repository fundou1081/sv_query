# L1 — 位精确性扩展（P7：直接拷贝 + 拼接）

**Status**: ✅ 完成（P7.1~P7.3，iter_295）
**Created**: 2026-10-26

## 目标

补两个剩余缺口（均为查询层，图结构不变）：

1. **直接拷贝** `assign y = a`（无 op 元数据）→ 同索引位映射，
   `one` 模式也能位精确（源位节点存在时）；多驱动（`y=a; y[3]=1'b1`）两个驱动都返回。
2. **纯拼接** `{a, b}` / `{a[3:0], b}` → 按表达式顺序切段，位查询只落到对应操作数位。

## 验收

- [x] `fanin(y[3])` = `{a[3]}`（`y=a`，a[3] 存在）

- [x] 多驱动 `fanin(y[3])` = `{1'b1, a[3]}`；`fanin(y[4])` 不含 1'b1
