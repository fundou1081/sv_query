# L1 — 常量位分解（P8）

**Status**: ✅ 完成（P8.1~P8.3，iter_296）
**Created**: 2026-10-26

## 目标

把常量从"总线粒度"分解到"值位"（查询层，图结构不变）：

1. **P8.1 拼接字面量段**：`s = {a, 4'b10}` → `s[0] = 1'b0`, `s[1] = 1'b1`
2. **P8.2 常量源切片**：`y = 4'hA` → `y[k]` 返回 `1'b0/1'b1`（无符号零扩展）
3. **位运算常量**：`a & 4'hF` → 该位常量 + 信号位；`bit≥4` 恒 0（信号不是依赖）

## 验收

- [x] `y=4'hA`：`y[0]=1'b0`, `y[1]=1'b1`, `y[3]=1'b1`
- [x] `y=4'hF` 8-bit：`y[5]=1'b0`（零扩展）
- [x] `y=0`（无宽度）：按 32 位零扩展 → `1'b0`
- [x] `a & 4'hF`：`s[1]={1'b1,a[1]}`；`s[5]={1'b0}`（不误导依赖）
- [x] `{a,4'b10}`：`s[0]=1'b0`、`s[1]=1'b1`、信号段 `s[5]=a[1]`
- [x] 常量位是查询层虚拟节点，图基线零差异
- [x] 全量门禁 2451 passed

## 边界

- 有符号字面量（`4'shF` 符号扩展）暂不分解
- 比较/逻辑/归约、变量移位、动态 part-select、函数调用：保持粗粒度
